# Sumativa 3 PRO205 — Tecnobox

## Contenido
- `Informe_Tecnico_Sumativa3_Tecnobox.docx`: informe editable.
- `codigo/`: versión defectuosa, versión refactorizada y pruebas.
- `evidencias/`: salida de consola y resultados de pytest.

## Ejecución
```bash
cd codigo
python -m pip install -r requirements.txt
python main.py
python -m pytest -v
```

## Git
Para crear el repositorio desde tu equipo, inicializa Git en la carpeta del proyecto y realiza commits por etapas. Después crea un repositorio vacío en GitHub/GitLab y enlázalo con `git remote add origin URL_DEL_REPOSITORIO`.
